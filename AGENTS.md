# Project Instructions

Treat this repository as a LaTeX master thesis project.

## Scope

- Thesis text is in this repository, mainly under `text/`.
- Frontend implementation is in a different repository.
- Figma design exists outside this repository.
- Backend API belongs to another thesis by Bc. Jakub Vondracek.

## Thesis Structure

1. Uvod
2. Analyza
3. Navrh
4. Implementace
5. Testing
6. Zaver

## Writing Rules

- Write in formal academic Czech.
- Write in first person singular where suitable (describe your own decisions and implementation process).
- Keep claims concrete; avoid broad statements without sources.
- Match the tone and depth of surrounding text in the current chapter.

## Writing Workflow

1. Keep and use `%` outline comments in the file.
2. If outline is missing, add a short outline first.
3. Write final prose from the outline points.
4. Do not remove existing outline comments unless explicitly asked.
