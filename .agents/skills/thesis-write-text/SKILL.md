# Write Thesis Text

1. Read the full target file before writing, so tone and context stay consistent.
2. Write only the requested part (section, subsection, subsubsection, or paragraph).
3. Rewrite existing text inside the requested part when it improves coherence.

## Rules

- Write in formal academic Czech.
- Keep first-person narrative where appropriate.
- Keep existing comments, especially outline comments.
- Match style with nearby paragraphs; if no local context exists, check earlier thesis chapters in `text/`.
- If comments require inspiration from an article or website, read that source first and then write the text.
