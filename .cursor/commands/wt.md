# Write Text

I will give you a name of a section, subsection, subsubsection or a paragraph and your job is to write the text of that part of the master thesis.

## Input

- Outline of the text written either as comments or as a first draft text in the part of the file

## Workflow

1. Read the whole file so that you get context of what are we writing about and what tone are we writing in.
2. Write the text of the given part. You can rewrite any text inside that part but don't remove any comments.

## Rules

- Write in Czech. 
- Write in a formal, academic format. You don't have to be overly academic but you should sound professional.
- Keep the style of writing as all the previous paragraphs in that file. If there are no paragraphs, you can look into files of previous chapters in the thesis.
- If in the comments there is written that the text should be inspired by or written by an article or a website, read the website or article and write it based on that.
